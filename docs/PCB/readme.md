В папке лежат файлы для создания печатной платы устройства практически без использования готовых модулей. Номера пинов в скетче указаны именно для этого варианта устройства. Плата имеет размеры для использования с коробочкой **100х60х30** мм.

![alt text](1003.png)

- **PCB_serial_alarm_1.5xx.zip** - архив с компонентами печатной платы в формате ***.pdf**; 
- **PCB_serial_alarm_1.5xx_lut.zip** - то же самое, но подготовленное для изготовления методом ЛУТ (toner transfer method); компоненты отзеркалены, все отверстия имеют диаметр 0,6 мм для лучшей центровки сверла, окончательные размеры приводите в соответствие с вашими компонентами; так же на плате есть три маркерных отверстия для совмещения сторон платы;
- **Gerber_serial_alarm_1.5xx.zip** - файл для заказа изготовления печатной платы, например, [здесь](https://www.pcbwave.com/);
- **EasyEDA/EasyEDA_project.zip** - файл проекта для импорта в программу [EasyEDA](https://easyeda.com/), если вдруг понадобится что-то изменить или доработать;
- **Schematic_serial_alarm_1.5x.png** - принципиальная схема устройства; отличается от приведенной в папке **docs** использованием **МК** и **RTC** в виде голых микросхем с соответствующей обвязкой;

На плате используется модуль семисегментного индикатора типоразмера **0.56** на драйвере **TM1637**, который впаивается в плату "бутербродом".

Все SMD-компоненты (кроме диодов) на плате имеют типоразмер **0805**. Вместо диодов **1n4007w** можно использовать любые подходящие, в том числе диоды Шотки для уменьшения падения напряжения.

![alt text](1001.png)

Вместо готового модуля **RTC** используется голая микросхема **DS3231**. Донором послужил мини-модуль.

Вместо **Arduino Pro Mini** используется голый микроконтроллер **Atmega328p** или **Atmega168p** с кварцевым резонатором **X1**. И то, и другое лично я, не мудрствуя лукаво, взял с платы **Arduino Pro Mini**.

![alt text](1002.png)

Для загрузки прошивки в **МК** на плате предусмотрен шестипиновый разъем **ICSP** для подключения программатора, например, **USBasp**.

Если не предполагается использовать загрузчик для заливки прошивки в **МК**, то разъем для подключения **UART** необязателен к установке, т.к. в коде взаимодействие с интерфейсом не предусмотрено. Так же в этом случае не нужны конденсатор **C4** и диод **D2**.

Остальные компоненты в пояснениях (как мне кажется) не нуждаются.
